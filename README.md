# screenie.exe

A central directory for PC-hosted Rec Room revivals, communities, downloads, and resources.

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Customize before publishing
1. In `script.js`, replace `discordInvite` with your permanent Discord invite URL.
2. Replace the sample project cards in `index.html` with verified revival information and official links.
3. Add your logo and approved project images in `assets/` if desired.

## Publish with GitHub Pages
1. Open the repository Settings.
2. Go to Pages.
3. Under Build and deployment, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then Save.

The site is a community directory and is not affiliated with Rec Room Inc.
