# screenie.exe community website

A simple, responsive community homepage for Rec Room Screen Mode players.

## Publish with GitHub Pages
1. Extract the ZIP.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the root of your `screenie.exe` repository.
3. If GitHub asks, choose to replace the existing files.
4. Commit the changes to `main`.
5. Keep GitHub Pages set to `main` and `/(root)` in Settings → Pages.

The site intentionally uses general community copy and does not invent a Discord invite URL. When you have your invite link, replace the `href="#community"` on the "Join the community" navigation link with your Discord invite URL.
